IDM 241 Alpha Build

TRIGGERS:

  • Hover On - User moves the mouse over the album cover
  • Hover Off - User moves the the mouse off the album cover
  • Click On - User clicks on the album cover

RULES:

  • When the mouse hovers over the album cover, it changes from the default cursor to the pointer cursor
  • When the mouse leaves the album cover, the cursor changes from the pointer cursor back to the default cursor
  • When the users clicks the album cover, a new tab opens and the user is redirected to the album's Spotify page
