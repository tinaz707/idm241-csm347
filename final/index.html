IDM 241 Final Description

Original Interface:

Wave To Earth Discography Page

A user can locate the object (an album cover) by going to the Wave to Earth website and selecting the Discography page in the navigation.

TRIGGERS:

Album Cover

  • Hover On
  • Hover Off
  • Click On
  • Click Off

Overlay Icons:

  • Hover On
  • Hover Off
  • Click On

Overlay Arrows:

  • Hover On
  • Hover Off
  • Click On

RULES:

Album Cover:

  • Hover On
    • Cursor changes from default to pointer
    • Album covers grows slightly
  • Hover Off
    • Cursor changes from pointer to default
    • Album cover returns to its original size
  • Click On
    • Overlay fades in from 1% to 100% opacity
  • Click Off
    • Overlay fades out from 100% to 0% opacity

Overlay Icons:

  • Hover On
    • Cursor changes from default to pointer
    • Icon changes from white to blue
  • Hover Off
    • Cursor changes from pointer to default
    • Icon changes from blue to white
  • Click On
    • User redirected to a new page that's related to that icon

Overlay Arrows:

  • Hover On
    • Cursor changes from default to pointer
  • Hover Off
    • Cursor changes from pointer to default
  • Click On
    • Right Arrow displays the next album on the grid
    • Left Arrow displays the previous album on the grid
    • Album description updates
