IDM 241 Final Description

Original Interface:

Wave To Earth Discography Page

A user can locate the object (an album cover) by going to the Wave to Earth website and selecting the Discography page in the navigation.

TRIGGERS:

Album Cover:

  • Hover On
  • Hover Off
  • Click On

Overlay Close Button:

  • Hover On
  • Hover Off
  • Click On

Overlay Icon Buttons:

  • YouTube Icon
    • Hover On
    • Hover Off
    • Click On
  • Spotify Icon
    • Hover On
    • Hover Off
    • Click On
  • Apple Music Icon
    • Hover On
    • Hover Off
    • Click On

Overlay Arrows:

  • Left Arrow
    • Hover On
    • Hover Off
    • Click On
  • Right Arrow
    • Hover On
    • Hover Off
    • Click On

RULES:

Album Cover:

  • Hover On
    • Cursor changes from default to pointer
    • Album cover grows slightly
  • Hover Off
    • Cursor changes from pointer to default
    • Album cover returns to its original size
  • Click On
    • Overlay fades in from 0% to 100% opacity

Overlay Close Button:

  • Hover On
    • Cursor changes from default to pointer
  • Hover Off
    • Cursor changes from pointer to default
  • Click On
    • Overlay fades out from 100% to 0%

Overlay Icon Buttons:

  • YouTube Icon
    • Hover On
      • Cursor changes from default to pointer
      • Icon changes from white to blue
    • Hover Off
      • Cursor changes from pointer to default
      • Icon changes from blue to white
    • Click On
      • User is redirected to the YouTube playlist for the album
  • Spotify Icon
    • Hover On
      • Cursor changes from default to pointer
      • Icon changes from white to blue
    • Hover Off
      • Cursor changes from pointer to default
      • Icon changes from blue to white
    • Click On
      • User is redirected to the Spotify playlist for the album
  • Apple Music Icon
    • Hover On
      • Cursor changes from default to pointer
      • Icon changes from white to blue
    • Hover Off
      • Cursor changes from pointer to default
      • Icon changes from blue to white
    • Click On
      • User is redirected to the Apple Music playlist for the album

Overlay Arrows:

  • Left Arrow
    • Hover On
      • Cursor changes from default to pointer
    • Hover Off
      • Cursor changes from pointer to default
    • Click On
      • Overlay information updates to display the previous album on the grid
  • Right Arrow
    • Hover On
      • Cursor changes from default to pointer
    • Hover Off
      • Cursor changes from pointer to default
    • Click On
      • Overlay information updates to display the next album on the grid
