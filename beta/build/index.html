RULES:

Ticket Button

  • Hover ON
    • Cursor changes from Default to Pointer
    • The button fills with blue
    • The button text changes to white
  • Hover OFF
    • Cursor changes from Default to Pointer
    • The button fills with white
    • The button text changes to black
  • Click ON
    • User redirected to Wave to Earth's Live Nation ticket page

Album Cover

  • Hover ON
    • Cursor changes from Default to Pointer
    • Album covers grows slightly
  • Hover OFF
    • Cursor changes from Default to Pointer
    • Album cover returns to its original size
  • Click ON
    • Overlay fades in from 1% to 100% opacity with information about the specific album
  • Click OFF
    • User clicks outside the overlay, the overlay fades out from 100% to 0% opacity

Footer Icon

  • Hover ON
    • Cursor changes from Default to Pointer
    • Blue fades in from the center until icon is filled
  • Hover OFF
    • Cursor changes from Default to Pointer
    • The icon changes back to black, the blue fading into the center
  • Click ON
    • User redirected to a new page that's related to that icon
