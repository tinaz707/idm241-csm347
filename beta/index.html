IDM 241 Beta Description

Original Interface:

Wave To Earth Homepage

  • ALBUM COVER Click on "Discography" located in the navigation to find the album covers
  • TOUR TICKET BUTTON Click on "Tour" located in the navigation, the button is labeled "TICKETS"
  • FOOTER ICONS From the Homepage scroll down to the footer to see the icons on the bottom right

TRIGGERS:

Album Cover

  • Hover On
  • Hover Off
  • Click On

Tour Ticket Button

  • Hover On
  • Hover Off
  • Click On

Footer Icons

  • Hover On
  • Hover Off
  • Click On

RULES:

Album Cover:

  • When the mouse hovers over the album cover, the cursor changes from the default cursor to the pointer cursor, and the album grows slightly
  • When the mouse leaves the album cover, the cursor changes from the pointer cursor back to the default cursor, and the album cover returns to its original size.
  • When the users clicks the album, an overlay pops up with information about the specific album

Footer Icon

  • When the mouse hovers over the icon, the cursor changes from the default cursor to the pointer cursor, and a blue color grows from the center of the icon which fills up the icon to a full blue
  • When the mouse leaves the button, the cursor changes from the pointer cursor back to the default cursor, and the color changes back black
  • When the users clicks the button, they are redirected to a new page that's related to that icon. For example the Spotify icon will redirect users to Spotify

Tour Ticket Button

  • When the mouse hovers over the button, the cursor changes from the default cursor to the pointer cursor, and the button fills up with the color black
  • When the mouse leaves the button, the cursor changes from the pointer cursor back to the default cursor, and is reverted to its original state with no color fill
  • When the users clicks the button, they are redirected to Wave to Earth's Live Nation ticket page
