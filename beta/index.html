IDM 241 Beta Description

Original Interface:

Wave To Earth Homepage

  • ALBUM COVER Click on "Discography" located in the navigation to find the album covers
  • TOUR TICKET BUTTON Click on "Tour" located in the navigation, the button is labeled "TICKETS"
  • FOOTER ICONS From the Homepage scroll down to the footer to see the icons on the bottom right

TRIGGERS:

Album Cover

  • Hover On
  • Hover Off
  • Click On
  • Click Off

Tour Ticket Button

  • Hover On
  • Hover Off
  • Click On

Footer Icon

  • Hover On
  • Hover Off
  • Click On

RULES:

Album Cover:

  • Hover On
    • Cursor changes from the default cursor to the pointer cursor
    • Album covers grows slightly
  • Hover Off
    • Cursor changes from the pointer cursor to the default cursor
    • Album cover returns to its original size
  • Click On
    • Overlay fades in from 1% to 100% opacity with information about the specific album
  • Click Off
    • User clicks outside the overlay, the overlay fades out from 100% to 0% opacity

Footer Icon

  • Hover On
    • Cursor changes from the default cursor to the pointer cursor
    • A blue color grows from the center of the icon which fills up the icon to a full blue
  • Hover Off
    • Cursor changes from the pointer cursor to the default cursor
    • The icon changes back to a black fill with the reversed animation of how it entered
  • Click On
    • User redirected to a new page that's related to that icon

Tour Ticket Button

  • Hover On
    • Cursor changes from the default cursor to the pointer cursor
    • The button fills up with the color black
  • Hover Off
    • Cursor changes from the pointer cursor to the default cursor
    • The button reverts back to fill up with the color black
  • Click On
    • User redirected to Wave to Earth's Live Nation ticket page
